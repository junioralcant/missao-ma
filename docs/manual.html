Parte 1

O que é o sistema

O Missão Maranhão conecta cada pessoa ao grupo de WhatsApp da sua própria cidade. A pessoa informa nome, CPF e escolhe o município — o sistema registra o cadastro e a encaminha direto para o grupo certo.

Para vocês, fica o controle: os links de cada cidade são cadastrados em uma área administrativa protegida por senha, e todos os cadastros recebidos podem ser consultados e exportados em planilha.

Senha de acesso A senha da área administrativa é entregue separadamente, por segurança — ela não faz parte deste documento. Guarde-a em local seguro e compartilhe apenas com quem for administrar os grupos.

Os 217 municípios já estão cadastrados

A lista de cidades vem da base oficial do IBGE e cobre todos os municípios do Maranhão. Ninguém consegue digitar uma cidade que não exista ou que seja de outro estado — o sistema só aceita municípios maranhenses.

Parte 2

Como a pessoa entra no grupo

O caminho tem quatro passos e leva menos de um minuto. Funciona no celular e no computador.

Informar o nome completo. Campo livre, obrigatório.
Digitar o CPF. A pontuação é preenchida sozinha enquanto a pessoa digita. O sistema confere se o CPF é válido de verdade — número inventado é recusado na hora.
Buscar a cidade. Basta começar a digitar que as sugestões aparecem. A busca ignora acentos e maiúsculas — quem digitar sao luis encontra São Luís do mesmo jeito.
Autorizar e entrar. O botão só fica ativo depois que a pessoa marca a autorização de uso dos dados — antes disso ele aparece apagado, como nas telas 1 e 2. Ao tocar, o cadastro é salvo e ela é levada automaticamente ao grupo da cidade dela.
Se a cidade ainda não tem grupo A pessoa não fica sem resposta: ela é direcionada para o grupo padrão que vocês configuram na área administrativa. Mesmo assim, o cadastro guarda a cidade real informada — assim vocês enxergam onde há demanda para abrir um grupo novo.
Cada CPF entra uma vez só Se a mesma pessoa tentar se cadastrar de novo na mesma cidade, ela apenas recebe o link do grupo outra vez, sem duplicar o cadastro. Se tentar em uma cidade diferente, o sistema recusa. Isso evita cadastros repetidos inflando os números.
Parte 3

Área administrativa

É onde vocês cadastram os links dos grupos e acompanham quem se inscreveu. O acesso é feito em www.missaoma.com.br/admin e exige senha.

Depois de entrar, o acesso fica guardado no navegador por 7 dias. Para sair antes disso, use o botão Sair no canto superior direito — importante se o computador for compartilhado.

Visão geral do painel

Cadastrar os grupos

Grupo padrão

É a rede de segurança do sistema: enquanto uma cidade não tiver grupo próprio, quem for dessa cidade cai neste link. Cole o link e clique em Salvar.

Grupo de uma cidade

Digite as primeiras letras do município, escolha na lista, cole o link do convite e clique em Cadastrar. O grupo da cidade sempre tem prioridade sobre o padrão.

Onde encontrar o link do convite No WhatsApp, abra o grupo → toque no nome do grupo → Convidar via link → Copiar link. Cole exatamente como está: o sistema aceita o link mesmo com os complementos que o WhatsApp adiciona no fim, e guarda a versão limpa.

Acompanhar os cadastros

A lista mostra todo mundo que se inscreveu, do mais recente para o mais antigo, com nome, CPF, cidade e data. O número ao lado do título é o total de inscritos.

Exportar para planilha

O botão Exportar CSV baixa um arquivo que abre direto no Excel ou no Google Planilhas, com acentuação correta. Use para conferir números, cruzar dados por cidade ou guardar uma cópia.

Cuidado com esses dados A planilha contém CPFs, que são dados pessoais protegidos pela LGPD. Não envie por grupos de WhatsApp, não publique e não compartilhe com quem não precisa. Guarde apenas enquanto for necessário.

Como ler os números

Se muitas pessoas de uma mesma cidade aparecem na lista e essa cidade ainda não tem grupo próprio, é o sinal de que vale criar um. Elas foram para o grupo padrão, mas a cidade real delas está registrada ali.

Rotina sugerida

Antes de divulgar. Configure o grupo padrão e os grupos das cidades onde a Missão já está organizada.
Toda semana. Abra o painel, veja de quais cidades vieram os novos cadastros e crie grupos para as que estão crescendo.
Sempre que criar um grupo novo. Cadastre o link na cidade correspondente — a partir daí, quem for dessa cidade já cai no grupo certo.
De tempos em tempos. Exporte o CSV e guarde uma cópia em local seguro.

Se algo não funcionar

O site fica no ar 24 horas por dia. Se alguém relatar que não conseguiu entrar em um grupo, o motivo mais comum é o link do convite ter expirado no WhatsApp — nesse caso, gere um link novo no grupo e atualize pelo botão Editar no painel.
